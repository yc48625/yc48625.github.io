# Xiaohe Xu Personal Homepage

This is a static personal academic homepage for GitHub Pages. It includes:

- A responsive personal profile layout
- A program-driven canvas animation
- An animated HTML presentation section
- A ResearchGate link: <https://www.researchgate.net/profile/Xiaohe-Xu-5>

## Preview locally

Open `index.html` directly in a browser, or run a simple local server:

```powershell
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Publish as a github.io site

1. Create a GitHub repository named `your-username.github.io`.
2. Upload `index.html`, `styles.css`, `script.js`, and `README.md`.
3. Open `https://your-username.github.io` after GitHub Pages finishes publishing.

If the target account is `plantbitree`, the repository name should be:

```text
plantbitree.github.io
```

and the site address will be:

```text
https://plantbitree.github.io
```
